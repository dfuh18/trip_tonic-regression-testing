keytypemeaning

A list with one entry per step the agent took during the turn, in order. Entries with kind = 'llm' are calls to the language model:
kind'llm'Marks a model call
seqintegerPosition in the turn (one counter for model and tool entries)
modeltextModel that answered
tokens_inputintegerPrompt tokens of this call
tokens_outputintegerCompletion tokens of this call
duration_msintegerHow long the call took
errortext, optionalProvider error, if the call failed

Entries with kind = 'tool' are the tools the model called (search_places, propose_plan, …):
kind'tool'Marks a tool call
seqintegerPosition in the turn
tooltextTool name
argsobjectArguments as sent; values cleared after 8 months, keys kept (D91)
started_attimestampWhen the call started
duration_msintegerHow long the call took
result_errortext | nullError the tool returned instead of a result (D11)
result_charsintegerSize of the result; the content itself is not stored
result_foundboolean | nullWhether a source had an answer (read_wikipedia, get_region_climate only; D40)
