# Third-party material in this folder

The files here are the stored references the factual-QA cases are judged
against (D23). They are what the agent's tools returned on the retrieval date,
kept verbatim, and they are **not** covered by this repository's MIT or
CC BY 4.0 licenses.

The credits are in this file and not in the files themselves on purpose. Each
reference file is passed to the judge whole, header comment included, so a
line added there would change what the judge was given and make later scores
incomparable with the ones the thesis reports.
